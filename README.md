# Website Syifa' Bakery

Website profil toko dan pemesanan menu untuk Syifa' Bakery yang menyajikan informasi produk roti, kue, minuman, promo hemat, dan kontak toko.

## Fitur Website

1. **Beranda (`index.html`)**
   - Menampilkan banner selamat datang dan ringkasan menu favorit.
   - Akses cepat untuk pemesanan menu utama.

2. **Halaman Menu (`HTML/menu copy.html`)**
   - Daftar varian produk (Croissant, Cheesecake, Muffin, Sandwich, dan Aneka Minuman Kopi/Non-Kopi).
   - Dilengkapi harga, gambar produk, dan tombol pemesanan.

3. **Halaman Promo (`HTML/promo copy.html`)**
   - Informasi paket bundling hemat dan kupon diskon.
   - Penjelasan keunggulan produk.

4. **Halaman Kontak (`HTML/kontak copy.html`)**
   - Formulir kirim pesan dan saran.
   - Informasi alamat, nomor telepon, dan jam operasional toko.

5. **Sistem Pemesanan (`JS/script.js`)**
   - Formulir pemesanan interaktif (nama pemesan, jumlah porsi, opsi tambah menu).
   - Perhitungan total biaya dan pembuatan struk transaksi digital.

## Teknologi yang Digunakan

- **HTML5**: Struktur dan konten halaman web.
- **CSS3**: Tata letak, styling tampilan, dan responsivitas.
- **JavaScript**: Logika pemesanan, validasi, dan cetak struk.

## Cara Menjalankan

1. Unduh atau clone repositori ini ke komputer.
2. Buka berkas `index.html` menggunakan web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
3. Gunakan menu navigasi di bagian atas untuk berpindah halaman.
